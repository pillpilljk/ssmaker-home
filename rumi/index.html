🇲🇳 Руми төхөөрөмжийн суулгагдсан програмуудыг удирдах үндсэн 3 алхам

루미보드는 별도의 PC나 스마트폰 연결 없이 본체의 전원 스위치, SELECT 스위치, START 버튼만으로 15가지 내장 프로그램을 즉시 탐색하고 실행합니다. Руми нь компьютер эсвэл ухаалаг утас холболгүйгээр зөвхөн цахилгаан унтраалга, SELECT товчлуур, START товч-оор 15 суулгагдсан горимыг шууд сонгон ажиллуулна.

STEP 1

전원 켜기 Асаах

루미 본체 후면의 전원 스위치를 켭니다. 눈에 불이 들어오며 준비 완료 대기 상태가 됩니다. Румигийн ард байрлах цахилгаан унтраалгыг асаана. Нүдний LED гэрэл асч бэлэн болно.

🇲🇳 Алхам 1: Төхөөрөмжийн цахилгааныг асаах
STEP 2

SELECT 스위치로 모드 탐색 SELECT-ээр горим сонгох

SELECT 스위치를 1회 누를 때마다 LED 색상과 음계 소리(도레미파...)가 1단계씩 증가하며 모드가 변경됩니다. (계속 누르면 1번 모드부터 다시 순환) SELECT товчийг 1 удаа дарах бүрт LED өнгө ба хөгийн авиа (До-Ре-Ми-Фа...) 1 шатаар нэмэгдэж горим солигдоно.

🇲🇳 Алхам 2: SELECT дарж өнгө, дуугаар горимоо тааруулах
STEP 3

START 버튼으로 즉시 실행 START-аар шууд эхлүүлэх

원하는 모드의 색상/소리가 확인되면 START 버튼을 누릅니다. 즉시 재미있는 언플러그드 활동이 시작됩니다! Хүссэн горимын өнгө, дуу таарсан бол START товчийг дарна. Тэр даруй сонирхолтой Unplugged даалгавар эхэлнэ!

💻 [초등부 & 중등 저학년] 엔트리 블록코딩 실습 매뉴얼

USB 연결부터 모터, 네오픽셀 RGB LED, 라인트레이서(line/lt/rt) 정밀 교차로 제어 및 격자 미션

Target: 초등 3~6학년 & 중등 1~2학년

🧠 엔트리 블록코딩과 루미 하드웨어의 통신 구조

"루미 로봇은 센서값(적외선 거리 센서, 바닥 라인 센서)을 컴퓨터로 전송하고, 컴퓨터의 엔트리가 두뇌(CPU) 역할을 하여 블록 코딩에 따라 연산한 뒤 모터나 LED 제어 명령을 루미로 다시 전송합니다."
따라서 엔트리 실행 중에는 컴퓨터와 루미가 지속적으로 블루투스 무선 통신을 유지해야 하며, 오프라인 설치형 엔트리를 사용하면 인터넷이 없는 환경에서도 100% 원활하게 수업할 수 있습니다.

🔌 1. 개발환경 설정과 무선 연결 5단계

STEP 1

USB 드라이버 설치

로봇과 컴퓨터 간 통신을 위해 CH340 / CH341 드라이버(CH341SER.exe)를 실행하여 설치합니다. (오류 시 UNINSTALL 후 재설치)

STEP 2

엔트리 오프라인 설치

playentry.org에서 PC용 엔트리 프로그램과 함께 '엔트리 하드웨어 연결 프로그램'을 다운로드하여 설치합니다.

STEP 3

동글 연결 & 루미 전원 ON

블루투스 동글을 컴퓨터 USB에 꽂고 루미 전원을 켭니다. (동글을 꽂고 바로 루미를 켜면 페어링 속도가 가장 빠릅니다!)

STEP 4

하드웨어 '라인코딩' 선택

엔트리 하드웨어 창에서 [라인코딩]을 찾아 선택하고 연결된 COM 포트를 연결합니다. (연결 성공 후 창 최소화)

STEP 5

초록색 블록 & 스피커 테스트

엔트리 블록 메뉴에 초록색 라인코딩 블록들이 나타나면 성공! [스피커 5 옥타브 도 음 0.25초 연주] 블록으로 첫 소리 테스트를 진행합니다.

⚙️ 2. 모터 제어 핵심 블록 및 엔지니어링 팁

연속 제어 기본 블록
wheel( 왼쪽 속도 , 오른쪽 속도 );

루미의 좌/우 모터 속도를 개별 설정합니다. 정지 명령이 실행되기 전까지 설정한 속도로 지속 회전합니다. (-20 ~ +20 속도 범위)

• wheel(5, 5); delay(1000); wheel(0, 0); ➔ 1초간 이동 후 정지
• ⚠️ 뒤에 wheel(0,0) 정지 블록을 넣지 않으면 로봇이 멈추지 않고 계속 달립니다!
동작 시간 제어
delay( ms 밀리초 );

설정된 시간(1000 = 1초)만큼 다음 실행을 잠시 멈춥니다. 주행 경로를 맞추거나 회전 각도를 정밀하게 제어할 때 사용됩니다.

• 🏎️ 관성 꿀팁: 직진 후 회전하기 전 짧게 delay(200)로 멈춰 서면 바퀴의 미끄러짐과 관성을 억제해 회전 정확도가 크게 향상됩니다!
일체형 거리 이동 블록
motor( 왼쪽 속도 , 오른쪽 속도 , 동작시간 ms );

wheel + delay를 하나로 합쳐 설정한 시간 동안 모터를 움직이는 편리한 블록입니다. (최대 동작 시간: 1000ms = 1초)

• 편차 보정 팁: 오른쪽으로 휘면 왼쪽 모터 속도를 1~2 낮춥니다. (예: motor(17, 19, 500))
• 정밀 직선 주행을 원할 때는 ffmotor 미세 보정 함수 블록을 사용합니다.

💡 3. 네오픽셀 RGB LED 제어 (눈 색상 및 조명 연출)

RGB LED 기본 블록
led( R밝기 , G밝기 , B밝기 , LED번호 );

루미의 눈에 내장된 풀컬러 네오픽셀 LED의 빛을 제어합니다.

• 밝기 범위: 0 ~ 255 (0: 끄기, 255: 최대 밝기)
• LED 번호: OUT1 ➔ 내장 눈 LED (OUT2, OUT3은 향후 확장 포트)

🛣️ 4. 바닥 센서 라인트레이서 (line / lt / rt 블록 정밀 해부)

🎯 라인트레이서 주행 전 필수: 오토센싱(Auto-Sensing 자동 보정)

바닥 센서는 검은색과 흰색의 빛 반사율 차이를 감지합니다. 교실 바닥 재질과 조명 밝기에 따라 감도가 달라지므로, 주행 전 오토센싱을 먼저 실행하여 센서 기준값을 최적화해야 로봇이 탈선하지 않습니다.

교차로 감지 직진 블록
line( 교차로 형태 , 직진 속도 , 추가 직진 시간 );

선을 따라 달리다가 지정한 모양의 교차로를 만나면 반응하는 자율주행 핵심 블록입니다.

• 교차로 형태: T1 (십자 ➕ 및 삼거리 ┳), L1 (좌측 갈림길 ㅓ), R1 (우측 갈림길 ㅏ)
• 직진 속도: 0 ~ 20 (기본 주행 속도)
• 교차로 감지 후 추가 직진 시간: 교차로 검은 라인을 통과하기 위한 시간 (0이면 감지 즉시 정지)
💡 추가 직진 시간이 왜 1 이상(50~150ms)이어야 할까요?

추가 직진 시간이 0이면 교차로 검은 선 위에서 즉시 멈춥니다. 그러면 다음 line 블록이 실행되자마자 "어? 이미 교차로네!" 하고 1칸만 가고 끝나버립니다.
따라서 교차로 검은 선이 끝나는 구간까지 살짝 더 직진(50~150ms) 시켜야 흰색 바닥에 정렬되어 다음 주행이나 회전이 100% 안정적으로 이어집니다!

교차로 회전 블록
lt( 속도 , 초기 모터 회전 시간 ); / rt( 속도 , 초기 모터 회전 시간 );

교차로에서 좌회전(lt) 또는 우회전(rt)을 수행하는 제자리 차동 회전 블록입니다.

• 모터 속도: 0 ~ 20
• 초기 모터 회전 시간: 회전 시작 시 센서 감지를 무시하고 강제로 회전하는 시간 (예: 100ms)
• (참고: 블록 이름의 lt1, rt8 등 뒤의 숫자는 엔트리 버전상의 표기이며 루미 제어 기능은 동일합니다.)
💡 초기 모터 회전 시간이 필요한 이유

로봇 센서가 이미 라인 근처에 있을 때 회전을 시작하면 센서가 즉시 검은색을 감지하여 충분히 회전하지 못하고 멈추는 오류가 발생합니다. 초기 시간(예: 100ms) 동안 센서를 무시하고 돌린 뒤, 그 후 센서로 검은색 감지 ➔ 흰색 감지 시 딱 멈추게 설계되었습니다.
• 좌회전 정지 기준: 왼쪽 센서
• 우회전 정지 기준: 오른쪽 센서

Hardware Specs
💡

본체 2버튼 즉시 제어

SELECT 버튼으로 1~15번 내장 프로그램을 선택하고, START 버튼으로 즉시 실행합니다. 유치원 유아도 부팅 대기나 마우스 조작 없이 3초 만에 스스로 작동할 수 있습니다.

👀

전방 듀얼 적외선(IR) 센서

사선 배치된 2개의 적외선 센서로 거리(cm)를 정밀 측정합니다. 펫 산책(3cm 유지), 장애물 회피, 손짓 기어 변속, 테레민 연속 주파수 연주를 구현합니다.

🛣️

바닥 듀얼 라인 센서

로봇 하단의 2개 센서가 흑/백 지면을 감지하여 고정밀 라인트레이싱을 수행합니다. 자동 감도 보정(오토센싱) 기능으로 바닥 밝기가 달라도 선과 교차로를 안정적으로 읽어냅니다.

🎵

Full-Color LED & 스피커

RGB LED 1개와 주파수 제어 스피커가 내장되어 무지개 감정 표현, 도레미파 음계 합주, 테레민 글리산도 사운드를 생생하게 출력합니다.

🎮

2.4GHz 무선 조종기 & 페어링

상하좌우(LU/LD/LL/LR) 방향키로 즉시 실시간 주행, L1 페어링 모드 버튼, RU(R_UP) 메모리 실행 버튼 탑재. 최초 1회 페어링(루미 SELECT 롱프레스 + 조종기 L1 누르고 전원 ON)을 완료하면 영구 기억되어, 이후에는 방향키만 누르면 즉각 1:1 무선 조종이 가능합니다.
